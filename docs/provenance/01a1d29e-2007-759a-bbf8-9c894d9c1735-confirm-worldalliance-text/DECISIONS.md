# Decisions

- The dialog sits in each editor that saves the content the ALL-2145 inventory found holding legacy links: the action editor (`action.body` and the action's other fields), the form builder, which also saves action and general update schemas, the reminder editor (`action_reminder` messages) and the staff directory (`user.staffLink`). The user deferred where it goes. One hook in the API client would cover every admin save but fire on saves that aren't authored content, such as records holding `@worldalliance.org` addresses. Switch to that if old links turn up in other editors. (agent decision)
- The match is case-insensitive and covers every string in what the editor saves, image URLs and option values included, since the user asked for any occurrence of the substring. The action editor scans only the fields the admin edits there (name, short description, body, images, image alt text, custom stat label, reviewers): its form state also holds the fetched action's read-only fields, and its authors' member-written bios would otherwise open the dialog on every save of an action whose author mentions worldalliance. (agent decision)
- The dialog lists each match as a short excerpt of the text around it rather than a field name, so one helper serves every editor, a form's images and options included, and the admin can find the text by searching for the excerpt. (agent decision)
- The form builder's existing unmatched-variable confirmation (`useSaveGate`) and this one show one after the other, each confirmed separately, rather than merging into one dialog. Both together are rare. (agent decision)
- Copy: title "Save with worldalliance text?", body "This mentions worldalliance. Links to worldalliance.org still redirect, but new ones should use thealliance.org. Names that still use worldalliance, such as the GitHub organization, can stay." followed by the excerpts, button "Save anyway". The body doesn't call every match the old domain, since the match is any `worldalliance` and some names that keep it, such as the GitHub organization and the Linear workspace, haven't moved. (agent decision)
- A confirmed save can still store legacy links, so this is not the ratchet ALL-2147 assumed. ALL-2146 and ALL-2147 are updated to say so, ALL-2147 noting it may need a second pass before ALL-2154. The user deferred this. (agent decision)
- The dialog's excerpts come from the helper the suite launch spelling check already uses, moved to `apps/admin/src/lib/textContext.ts`, so both show the same amount of context. It marks each cut side, and both show "…" only where the excerpt actually cuts the text, where the launch check used to show it on both sides always. It keeps the launch check's 20 characters a side, since those excerpts are part of its stored dismissal keys. (agent decision)

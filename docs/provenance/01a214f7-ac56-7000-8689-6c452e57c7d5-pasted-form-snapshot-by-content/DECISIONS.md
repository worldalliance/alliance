# Decisions

- **Cause.** `insertForm` spread the pasted `taskForm`, clearing its `id` but keeping `formSnapshotId`. A form's content lives in the shared, hash-deduplicated `form_snapshot` row, so in another environment the new form pointed at whichever snapshot had that id. PR #1081 (task directory for "Give a pasted action its own form") removed the pasted `taskFormId` but left this. (agent decision)
- **Pasted content goes through the same validation as `POST /tasks/createForm`.** That validation (zod `formSchema` plus `validateFormSchema` with formula source forms) moved from `TasksService` into `server/src/tasks/parse-form-schema.ts` so both paths share it. A pasted form whose formulas read forms missing in the target environment is refused, not saved half-broken, per root `AGENTS.md` **Fail loudly**. (agent decision)
- **Only the title is copied from the pasted form row.** Its id, slug, timestamps and snapshot ids belong to the source environment; the slug is regenerated by `insertForm` and the snapshot found or created by content, and `insertForm` records it in the form's history. (agent decision)
- **Actions already pasted with the wrong form are not repaired in code.** They are re-pasted once this is live. (agent decision)

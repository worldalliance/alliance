# Decisions

- **Out of scope:** the signed-in Alliance member message, a portal in `apps/mobile`, and switching the participant bar from counting Alliance members to counting Kora participants. The user was asked about all three and picked none, so they stay out. Kora sign-up exists only on the web, so `apps/AGENTS.md`'s web–mobile parity rule has nothing to mirror on mobile yet. The bar's member count is a known quirk and may deserve its own task.
- **Video format:** `chatbot-ranking-tool.mov` is re-encoded as a 482 px, 30 fps H.264 MP4 with no audio and faststart (`review-demo.mp4`, about 200 KB), with its first frame saved as `review-demo-poster.jpg`, both in `apps/frontend/public/assets/chatbot-safety/`. `.mov` doesn't play reliably outside Safari. The video is silent and decorative, so it gets an `aria-label` and no captions.
- **Which hero media shows:** `useSignedInParticipant` in `useKoraParticipant.ts` decides between the video and the images. It reads the same query as `KoraSignIn`, through the shared `koraStateQuery` options, and returns no participant while the member session is loading or when a member is signed in. That matches `KoraSignIn`, which shows the member message ahead of any participant state.
- **Card placement:** the portal stays inside `KoraSignIn.tsx`, renamed from `SignedIn` to `Portal`. It shares `SUBMIT` with that file, and the file stays under 500 lines.
- **Disabled button:** the shared `Button` type requires an `onClick` for `type="button"`, so the disabled start button passes a no-op. It gets a real handler once the review tool exists.
- **Launch date:** `PORTAL_START_LABEL` spells out "November 17" itself and doesn't derive it from `SIGNUP_NOTE`. That note says "November 17th", and building one string from the other would make both harder to read.
- **Sign-out:** with the button gone, the frontend's `signOut` mutation had no callers, so it's deleted. The server's `POST /kora/sign-out` endpoint and its generated client function stay. Removing them is a server change outside this task.

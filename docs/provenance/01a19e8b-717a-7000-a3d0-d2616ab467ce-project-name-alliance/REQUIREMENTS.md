- The project is called the Alliance. (user)
- New names use `alliance` as the tag. Other names, such as the `worldalliance.org` and `thealliance.org` domains and the `worldalliance` GitHub organization, exist only where `alliance` itself was unavailable, and are not a pattern for new names. (user)
- A new Apple identifier (bundle id, Services ID, and the like) tries `alliance` first, e.g. `com.alliance.alliancemobile.<variant>`, and falls back to the existing prefix (`alliancefoundation`, `thealliance`) only if `alliance` is taken. Related ids may end up with different prefixes. (agent-proposed, user-approved)

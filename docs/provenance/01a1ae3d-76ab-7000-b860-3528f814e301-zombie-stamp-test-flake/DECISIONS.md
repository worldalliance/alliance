- The failure is a race in the test "a zombie has no stamp" (`scripts/lib/worktree-process.test.ts`), not a bug in `process_stamp`: the test exited 2, its own precondition that the child shows as a zombie. Two races fed it: the old child (`true`) could exit before its parent shell exec'd into `sleep`, so the shell reaped it and no zombie ever existed; and the fixed 0.5s wait could end before a loaded runner showed the zombie. The child now sleeps 0.5s so it outlives the exec and `sleep`, which never reaps, inherits it, and the test polls `ps` for up to 3s. Under CPU load the old test failed 2 of 20 runs locally, the new one 0 of 60. (agent decision)
- The parent's stderr goes to /dev/null so it holds no pipe `spawnSync` waits on; the test returns once bash exits instead of waiting out the parent's 10s sleep. (agent decision)

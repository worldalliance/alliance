# Decisions

- **Tasks page order.** On desktop the tasks page goes back to its order before `docs/provenance/01a1f44f-786e-7000-825e-995af647ada7-home-updates-carousel`: general updates above the "Tasks" heading, then the task card, then the activity feed. That task had moved general updates below the task card on every width, inside a wrapper that rendered even when empty, which put an extra page gap (4rem on desktop) between the task card and the activity feed. Below the desktop width, the update carousel and general updates stay under the task card, as that task decided. (agent decision)
- **Fixed photo area.** A photo can no longer size its card. On web each mosaic tile's image is absolutely positioned within its tile, the photo area clips to its 3:2 box, and a single row is pinned with `grid-rows-1`. On mobile each tile's `Image` fills it with `StyleSheet.absoluteFill`. A photo of any proportion is cropped by `object-cover`, so cards in a row stay the same height. Checked with a 4:15 test photo on web and mobile web: every card in the first two rows of the web "Project updates" page measured 448 px tall with a 1.5 photo-area ratio. (agent decision)

# Decisions

- Use GitHub-hosted disposable runners: macOS for iOS, Ubuntu with KVM for Android. Both provide browser tooling. The dispatcher selects the available native platform; the agent chooses journeys and interactions.
- Require a manual dispatch identifying a PR and its exact head SHA. Resolve the base SHA once and validate repository write access for the triggering and rerunning actors. Workflow code comes from the dispatched trusted ref, independently of the PR under test.
- Install host tools before running PR code. Run dependency installation and app builds inside Claude after a root-owned loopback credential proxy starts and sudo access is removed. Give the capture job read-only GitHub permissions and no application, deployment, AWS, or signing secrets. The proxy holds the existing Claude OAuth credential in root process memory, exposes only message and token-count endpoints, and gives Claude a non-secret placeholder credential; a job timeout bounds access duration, but is not a dollar spending limit.
- Publish from a fresh Ubuntu job, validate the report and regular PNG files, and link the 14-day screenshot artifact in a PR comment without executing artifact contents. Recheck the PR head before posting. GitHub CLI attachment uploads reject the built-in Actions token, so artifact links avoid requiring a separate personal token.
- Reuse the existing Expo application, synthetic dropdown fixture, visual-test mode, Playwright, Maestro, and simctl. Leave the deployment baseline workflow independent: this feature compares pinned PR revisions and allows exploratory interactions.
- Do not reuse the SQL snapshot for remote evidence: use synthetic fixtures or agent-created synthetic records so public artifacts contain no real personal information.
- Validate an unmerged workflow using a temporary push trigger only on the sample branch. The implementation workflow remains manual-only. This avoids changing the default branch merely to register workflow_dispatch.

- Use Claude's supported `--output-format stream-json --verbose` spelling. Preserve pipeline failures and require a successful terminal result event. Disable project settings and inherited MCP configuration for the capture session.

# Decisions

Each draws on `EVIDENCE.md`. ALL-2013's own proposals were set aside per `REQUIREMENTS.md`; where a decision matches one, it is because the evidence led there.

- **Trigger only when a change grows a file past 500 or past its waiver; drop "a file past 500 is already overdue for a split".** The research recommends preventing unexplained growth over demanding wholesale splitting of existing files; the dropped sentence pushed toward the latter.
- **Keeping a file whole is decided after the codex consult.** That keeps the second opinion on the case where self-judgment is weakest, and splitting only reduces context when an agent can read one piece without the rest.
- **The waiver is a comment the lint rule parses, `/* alliance/max-lines <ceiling> -- <reason> */`, rather than an `eslint-disable`.** An `eslint-disable` switches the rule off, so it can't hold a ceiling, and ESLint's bulk suppressions count one finding per file, which lets a suppressed file grow. A comment in the file is what the next change to it reads, where a commit message would go unseen. In a language where `/* */` isn't a comment, the waiver takes that language's comment syntax.
- **`alliance/max-lines` is its own rule, not a wrapper around core `max-lines`.** The core rule takes no per-file ceiling. The new rule keeps the old counting (non-blank lines, comments included) so existing counts carry over. It looks for the waiver anywhere among the file's comments, so a waiver below a header comment still counts, and treats a `/** alliance/max-lines … */` or `// alliance/max-lines …` as a malformed waiver, naming the `/* */` form, rather than missing it; it reports any waiver after the first, so a stale duplicate can't sit unchecked. The waiver it offers a file past the limit counts its own line, so pasting it passes; whether a file is back within the limit is judged without the waiver, so a waiver only its own line keeps past 500 is reported for removal. Ceilings in multiples of 50 (`REQUIREMENTS.md`) mean two branches that each add or remove a few lines rarely both edit the waiver line, which with exact counts conflicted or, merged cleanly with the same delta, left `main` past its ceiling. Waivers apply to the TypeScript files the rule lints. For other hand-written source, the `AGENTS.md` rule applies without lint.
- **Cite _Clean Code_ through its publisher listing only.** The research's page scan was hosted on a user-upload site, likely an unauthorized copy; the listing carries the same citation.

- Legacy `/api`, `/events` and `/socket.io` answer `410 Gone` rather than redirect, departing from ALL-2152's "redirect like other paths". A redirected API call reaches thealliance.org without its bearer token on browsers, Android and iOS, and a `301`/`302` turns a POST into a GET, so a straggling build would look signed out instead of retired; a websocket handshake does not follow a redirect (`EVIDENCE.md`, redirects). `410` is HTTP's code for a resource removed on purpose. (agent decision)
- Legacy `GET` and `HEAD` `/api/images/<key>` redirect `301` to the same path on thealliance.org, which itself redirects to CloudFront. Image loads carry no credentials and browsers and React Native follow redirects for them (`EVIDENCE.md`, images). Permanent at once, unlike the page redirects ALL-2141 still holds at `302`: the target serves the same image whether or not this change is rolled back, so a cached `301` can't strand anyone. Other methods, such as `POST /api/images/uploadImage`, get the `410`, since a `301` would turn the upload into a `GET` that 404s. (agent decision)

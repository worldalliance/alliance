- Web `PostFormPage` already creates posts through `useForumPost(undefined).create`; mobile `forum/create.tsx` calls `forumCreatePost` directly. Mobile moves onto the same mutation, so `useForumPost` is the one place posts are created.
- A created post belongs in the forum list. Web's list reloads on every mount, but mobile's list screen stays mounted under the create screen and mobile doesn't refetch on focus, so a post made on mobile was missing from the list until pull-to-refresh. `create` now invalidates the list through `invalidateForumPosts`, which sits in `useForumPosts.ts` beside `dropForumPost`, so every write to the list cache stays in the file that owns it. The invalidation isn't awaited, so the form navigates without waiting on the list reload.
- The created post itself stays out of the single-post cache, as before: the create response lacks the action and tags the post page shows.
- `create` keeps the default `networkMode`. TanStack's online detection always reports online on React Native, so on mobile it behaves like the raw call did. Web already used this mutation.

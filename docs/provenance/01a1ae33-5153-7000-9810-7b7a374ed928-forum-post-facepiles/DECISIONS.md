# Decisions

- Callers that used `findOnePost` only as a visibility check (`LikesService.getPostLikers`, `getCommentLikers`, `FeedMembersService`) call `assertPostVisible`, so they don't load every liker of a post they throw away. (agent decision)
- `ForumLikesService.likePostOrComment` checks post membership against `likesIds` rather than the full `likes` relation. Comments have no liker-id column, so the comment branch still loads `likes`. (agent decision)
- `PostDto` takes the facepile as a separate `facepile` argument, as `CommentDto` does, rather than overwriting `post.likes` with it. `likeCount` and `likedByMe` read `likesIds`, and a truncated list stored on `post.likes` would turn into a wrong count wherever `likesIds` is missing. Services return `PostDtoArgs` (`{ post, facepile }`), which is what `findAllPosts` already returned. (agent decision)
- The create response sends `facepile: []`, since a new post has no likers. (agent decision)
- `updatePost` and `removePost` check authorship against `findOneVisiblePost`, so they don't load a facepile they throw away, and `updatePost` loads the facepile only for its response. (agent decision)
- `forum-admin.service.ts` needs no change. Its post loads (`findPostForAdmin`, `getPostsForAdmin`) don't load likes, and the `likes: true` at `togglePinComment` is for a comment, whose `CommentDto.likedByMe` needs the full relation. (agent decision)
- The e2e spec gives the post `LIKE_FACEPILE_LIMIT + 1` likers and compares each endpoint's `likes` against the likers endpoint's first page (`GET /likes/post/:id/users?limit=LIKE_FACEPILE_LIMIT`), so it pins the cap and order as well as the shape. Every liker has a cluster and a contract event so the comparison covers `cluster` and `lastContractEvent`, which the plain `likes` relation didn't load. (agent decision)
- Removing the action endpoint's tests drops no coverage of scheduled-post visibility: the same filter (`addPostVisibilityFilter`) has its own tests through the index, detail and profile endpoints in `forum.e2e-spec.ts`. (agent decision)

# Decisions

- **Environment settings beyond the branch policy are left at the provider defaults** (`can_admins_bypass` true, `prevent_self_review` false, no reviewers, no wait timer), which match every environment's live settings (EVIDENCE.md, Live state). Agent decision.
- **`prevent_destroy` on the environments**: deleting one deletes its deployment history, so removing an environment's role from the trust fails the plan loudly instead. Agent decision.
- **Environments come from roles whose trust `sub` is `…:environment:<name>`**, so `review` and `parameter-drift` add none, and a new environment-gated role creates its environment with no extra flag. Agent decision.
- **The derivation fails the plan rather than letting the trust and the rules disagree**: a second role trusting the same environment is a duplicate key, and a precondition rejects any environment ref other than a literal `refs/heads/<branch>` or `refs/pull/*/merge`, since IAM and GitHub read wildcards differently and tags aren't branches. Agent decision.
- **`owner` and repository name become locals** (`github_owner`, `github_repo_name`) that `github_repo` is built from, so the provider and the OIDC subjects name the repository once. Agent decision.
- **The import blocks live in `terraform/github-import.tf`, which the PR's last commit deletes; the import is applied from the commit before it, after the user's review and just before merge**. Between that apply and the merge, the shared state holds GitHub resources `main` has no config for, and an apply from `main` would destroy them, so the merge follows the apply at once; if the merge falls through, `terraform state rm` the GitHub addresses. This departs from HashiCorp's suggestion to keep them as a historical record (EVIDENCE.md). They import by fixed policy ids into addresses derived from the trust map, so once kept they would break a later change: a policy dropped from the trust leaves an import with no target, and one re-added later imports an id GitHub has deleted. Agent decision.
- **The lock file keeps the AWS (4.67.0) and random (3.9.1) versions already selected locally** and adds `integrations/github` 6.13.0, the current release, constrained `~> 6.13`. Agent decision.

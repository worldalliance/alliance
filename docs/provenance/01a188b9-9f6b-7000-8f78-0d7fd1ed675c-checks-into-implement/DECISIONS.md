# Decisions

- The root Typechecking rule stays available to every agent because invoking `tsc` directly gives incorrect results here. The implementation skill lists when to run the package checks.
- The root pointer routes verification of any change to the Checks section, including documentation, workflows, and reviews. Verification-only work skips the implementation steps.
- Dependency guidance stays in the root instructions because it applies when adding a dependency, before verification.

# Decisions

- Timeline descriptions keep their "Step N:" prefix, since the timeline renders `description` verbatim and every other step carries one.
- Typos in the supplied copy are corrected: "shoudl" → "should", "Participant will" → "Participants will".
- Sections keep their existing headings and blank-line-separated numbered list. Bulleted sections become blank-line-separated paragraphs so each line renders as its own paragraph; the numbered steps are not bullets and stay a list.

- **The images fix lives in `withSlideAspectRatio`** (`apps/mobile/lib/slideAspectRatios.ts`): react-native-web keys its image load effect on the `onLoad` prop, so a render caused by `onLoad` loads the image again and loops. Returning the same object for an unchanged ratio makes React skip that render, and a stable `onLoad` handler stops the redundant reload. A pure function because mobile tests cover logic, not rendered components; its test fails on the old merge.

- **The images fix lives in `withSlideAspectRatio`** (`apps/mobile/lib/slideAspectRatios.ts`): react-native-web keys its image load effect on the `onLoad` prop, so a render caused by `onLoad` loads the image again and loops. Returning the same object for an unchanged ratio makes React skip that render, and a stable `onLoad` handler stops the redundant reload. A pure function because mobile tests cover logic, not rendered components; its test fails on the old merge.
- **The withdrawal sheet matches web's menu in title, icons, selected style, and showing the detail box and Withdraw button only after a reason is picked.** The title is shared copy (`withdrawalOptions`). The icon map is repeated per platform because web and mobile import icons from different lucide packages. "On vacation" still opens `/membership` on mobile and `/membership#away-periods` on web, a routing difference outside this task.
- **The card's time estimate uses the unfilled `TaskTimeInfo`, now sized like web's (16 pt icon, base text).** The action page keeps the filled pill; it was not part of the card comparison.
- **Web radios and checkboxes take green from `accent-color: var(--color-green)` on the frontend's `html`.** `accent-color` is the standard CSS property for native form controls and is inherited, so one rule covers every member-facing radio and checkbox, not only the task form's; a control that sets its own accent, such as `LargeCheckbox`, keeps it. The `text-blue-600` / `text-red-600` classes on the task form's inputs did nothing without a forms plugin, and neither did the border classes a native control ignores, so both are removed; the focus ring moves from blue to the same green. Admin keeps the browser default: it is a staff tool, outside the web–mobile comparison.
- **Textareas are unchanged.** Both platforms already size a textarea from `rows || 3` (`textareaMinRows` on web, `TextareaInputField` on mobile). The taller one-row box seen on mobile came from react-native-web, which drew a resizable `<textarea>` taller than the `minHeight`.
- **Expo web is not a faithful stand-in for native typography.** React Native Web writes `fontFamily: "Source Sans 3"` unquoted, which CSS rejects, so the web build falls back to the system font and loses weight-specific faces. Text widths there run wider than native.

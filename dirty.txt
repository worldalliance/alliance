Before clearing this file:

1. Update the Mailgun SMTP credentials for thealliance.org — SMTP_HOST, SMTP_USER,
   SMTP_PASSWORD under Settings > Secrets and variables > Actions > Secrets, for the
   production environment.
2. Add MAIL_FROM on the Variables tab for the production environment. Value,
   angle brackets included:
       Alliance <alliance@thealliance.org>
   The server exits at boot if it is unset while mail sending is on, and the
   production deploy fails early if the variable is missing.

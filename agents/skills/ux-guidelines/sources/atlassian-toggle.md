> Use toggles to let people turn something on or off instantly. For example, if you need to enable public access to a resource.
>
> - The toggle component doesn't work within the form component by default. This is because the toggle is supposed to make change happen instantly, not after pressing a submit button. For options that require a button press to apply the setting, use a [checkbox](https://atlassian.design/components/checkbox).

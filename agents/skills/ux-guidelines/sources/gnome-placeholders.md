# Placeholder Pages

Source: <https://developer.gnome.org/hig/patterns/feedback/placeholders.html>

Retrieved: 2026-11-06

GNOME Human Interface Guidelines, by the GNOME Design Team; the site and its repository (https://gitlab.gnome.org/Teams/Websites/developer.gnome.org-hig) state no license. Excerpts only, quoted for the guidelines items that cite this page; the page itself has the rest.

---

> Symbolic placeholder pages should be used in other spaces that might often contain content, but which are empty, such as empty folders, albums or search results views.
>
> All placeholders should include a heading which communicates the empty state and provides guidance. For example, “Empty Folder”.
>
> It is often helpful to include a description which provides additional guidance, such as how to add items. For example, “Use the **+** button to add items.”
>
> It can also be a good idea to include controls for relevant actions, such as adding content or starting a setup assistant. This is one place where the [suggested button style](https://developer.gnome.org/hig/patterns/controls/buttons.html#button-styles) can be appropriate.

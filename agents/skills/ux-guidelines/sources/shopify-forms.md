> Forms should be saved using the Polaris [Data Save Bar](https://shopify.dev/docs/api/app-home/app-bridge-web-components/save-bar) API. This also applies to [forms within app windows](https://shopify.dev/docs/api/app-home/app-bridge-web-components/app-window). Continuous data validation or auto-save for forms is incongruous with the standard Shopify admin save UX.

> Links are used as navigational elements. They navigate users to another location, such as a different site, resource, or section within the same page.
>
> Do not use links for actions that will change data or manipulate how it is displayed, change a state, or trigger an action. Instead, use [buttons](https://carbondesignsystem.com/components/button/guidelines) to guide users to specific actions.

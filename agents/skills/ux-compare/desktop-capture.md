# Capturing the desktop app

The desktop app needs `bun install` and `bun run build` in the checkout's `agents/desktop/` first, and Node for the reason `agents/README.md` gives for the app's tests. `capture.mts` launches it through Playwright's Electron support with `args` of the absolute path of the checkout's `agents/desktop/` and `--user-data-dir=<output dir>/user-data`, so a capture never touches the developer's Alliance agent profile, and deletes that directory once the app closes, so the output directory holds only screenshots. These are the args `agents/desktop/e2e/app-args.ts` gives the tests, but its `appArgs()` calls `test.info()`, which throws outside the test runner, so the script builds them itself. Like the tests, which set it in `agents/desktop/playwright.config.ts`, it sets `ALLIANCE_AGENT_HEADLESS=1` so no window opens on the user's screen, passing `env: { ...process.env, ALLIANCE_AGENT_HEADLESS: "1" }`, since an `env` replaces the app's whole environment. Unlike the tests, it sets `executablePath` to what `require("electron")` returns resolved from `agents/desktop/` (through `createRequire`), since it runs from the checkout's root.
